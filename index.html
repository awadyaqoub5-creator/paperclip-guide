Paperclip: شغّل فريق agents كأنك صاحب شركة، كل واحد له مدير وميزانية

Paperclip: run your AI agents like a company, with a manager and a budget for each

بأمر واحد تنزّل Paperclip على جهازك، تكتب هدف لشركتك، وتعيّن فريق من الـ agents. كل agent له مدير يرجع له، ومهام واضحة، وسقف صرف ما يتعداه. والقرارات الكبيرة ما تمشي إلا بموافقتك.

هالدليل لمين؟

لك إذا صرت تشغّل أكثر من agent وتلخبطت بينهم وما تدري مين يسوي وش. ولك بعد إذا ودك تجرب فكرة "فريق agents" بدون ما تبنيه من الصفر.

كلمات لازم تعرفها

Paperclip
برنامج مفتوح المصدر برخصة MIT، يرتّب الـ agents عندك على شكل شركة. يشتغل على جهازك ومجاني.
Agent
برنامج ذكاء اصطناعي يشتغل لحاله، مثل Claude Code أو Codex أو Gemini CLI. داخل Paperclip تعطيه وظيفة.
Org chart
الهيكل التنظيمي. كل agent له مدير واحد، والـ CEO فوق الكل.
Heartbeat
النبضة اللي تصحّي الـ agent لما توصله مهمة أو رسالة أو يجي موعد مجدول.
Budget
حد أعلى للصرف، على مستوى الشركة أو الـ agent أو المشروع. إذا وصله، الشغل يوقف لحاله.

الخطوات

  1. اعرف وش اللي بتنزّله

    Paperclip مو agent. هو المكتب اللي الـ agents يداومون فيه: يوزع الشغل، يتابع المصاريف، ويرتب مين يرجع لمين. البرنامج نفسه ببلاش، بس الموديلات اللي تشغّل الـ agents مو ببلاش. تدفع لمزوّد الموديل، سواء بمفتاح API أو باشتراك.

    المصدر: المستودع الرسمي على GitHub، برخصة MIT.

  2. نزّله بأمر واحد

    تحتاج Node.js نسخة 24.11 أو أحدث. تأكد من النسخة أول، وبعدها شغّل أمر التثبيت:

    $ node -v
v24.11.0
$ npx paperclipai@latest onboard --yes

    الأمر يسوي لك نسخة محلية فيها قاعدة بيانات Postgres مدمجة، يعني ما تحتاج تركّب شي ثاني.

    إذا طلع لك E404: غالباً عندك npm registry خاص. ضيف على الأمر --registry https://registry.npmjs.org

  3. اكتب هدف الشركة

    الـ CEO ياخذ الهدف ويقسمه مهام على الفريق. كل ما كان الهدف واضح وله رقم وموعد، كل ما كان التقسيم أحسن. "أبغى مشروع ناجح" ما ينفع. "أطلق صفحة هبوط وأجيب 100 تسجيل خلال 30 يوم" ينفع.

    برومبت: صياغة الهدف
    ساعدني أكتب هدف شركة لفريق agents في ثلاث جمل:
١) وش النتيجة اللي أبغاها بالضبط (برقم يُقاس)
٢) الموعد النهائي
٣) وش الممنوع أو خارج النطاق
فكرتي المبدئية: [اكتب فكرتك هنا]

  4. عيّن الفريق واختار وش يشغّل كل واحد

    ابدأ بالـ CEO، وبعدها ضيف الوظايف اللي تحتاجها: مطوّر، مصمم، مسوّق. حدد لكل واحد مديره، واختار الأداة اللي تشغّله (Claude Code أو Codex أو غيرها). نصيحتي: لا تبدأ بأكثر من 3 أو 4 agents. فريق صغير تفهمه أحسن من فريق كبير يلخبطك.

    برومبت: وصف وظيفة (بالإنجليزي)
    Write a job description for an AI agent joining my company as [ROLE].
Include: its main responsibilities, who it reports to, what it must
never do without approval, and how it should report progress.
Keep it under 150 words.

  5. حط سقف للصرف قبل ما تشغّل أي شي

    هذي أهم خطوة بالدليل كله. حط ميزانية للشركة وميزانية لكل agent، وفعّل التنبيه قبل ما يوصل السقف. لما الصرف يوصل الحد، الشغل يوقف لحاله.

    انتبه: الإيقاف يعتمد على الصرف المسجّل، فممكن مهمة شغالة تكمّل شوي بعد السقف. ابدأ بميزانية صغيرة وتابع صفحة التكاليف كل يوم في الأسبوع الأول.

  6. خل القرارات الكبيرة تنتظر موافقتك

    قبل ما يتوظف agent جديد أو تتغير الاستراتيجية، Paperclip يوقف ويطلب موافقتك. خصص وقت مرة أو مرتين باليوم تراجع فيه الطلبات: توافق، ترفض، أو توقف agent إذا شفته ماشي غلط.

  7. قرر وين يشتغل: جهازك ولا سيرفر

    على جهازك، الفريق يشتغل بس وجهازك شغّال. إذا تبغاه يشتغل 24 ساعة، حطه على سيرفر أو جهاز ما يطفي، تقدر تستخدم Docker للنشر، وتدخل عليه من برا عن طريق شبكة خاصة مثل Tailscale.

    مهم: لا تفتح لوحة التحكم على الإنترنت بدون تسجيل دخول.
    برومبت: خطة النقل لسيرفر
    عندي Paperclip شغّال على جهازي وأبغى أنقله لسيرفر VPS يشتغل 24 ساعة.
اكتب لي خطة خطوة بخطوة: تجهيز السيرفر، التثبيت بـ Docker، نقل البيانات،
والوصول الآمن عن طريق Tailscale بدون ما أفتح أي منفذ للإنترنت.

برومبتات جاهزة للنسخ

مراجعة أسبوعية للفريق
راجع شغل الفريق هالأسبوع وطلّع لي:
- أي agent صرف أكثر من المتوقع وعلى وش
- المهام اللي تكررت بدون نتيجة
- اقتراح واحد يقلل الصرف الأسبوع الجاي
تقسيم الهدف قبل الـ CEO
قبل ما أعطي الهدف للـ CEO، قسّمه لي لخمس مهام رئيسية.
لكل مهمة: مين المناسب لها من الفريق، وكم تاخذ تقريباً، ومتى نعتبرها "خلصت".

الخلاصة

Paperclip ببلاش، والموديلات لا. حط الميزانية والموافقات قبل أول تشغيل، وبعدها خل الفريق يشتغل وأنت تتابع.
